## 1. Описание проекта и архитектура

Приложение представляет собой мобильный интерфейс (390px, вертикальный адаптивный layout, стилизованный под мобильное приложение) для гостевого просмотра сетевых активностей и параметров полосы пропускания Wi-Fi роутера.

### Ключевые требования лабораторной работы:
- **Никакого Redux и никакого `React.createContext`**: для передачи общего состояния карточек между маршрутами используется встроенный механизм React Router — `Outlet context` (`<Outlet context={{ activities, setActivities }} />` и хук `useOutletContext<AppOutletContext>()`), как предписано в методических указаниях.
- **Компоненты React-Bootstrap**: формы (`Form`, `Form.Control`, `Form.Range`, `Form.Select`), карточки (`Card`), кнопки (`Button`), бейджи (`Badge`), спиннеры (`Spinner`), тултипы (`OverlayTrigger`, `Tooltip`) и навигация (`Navbar`, `Nav`).
- **Изображение и видео по умолчанию**: в проекте (`public/default.png`, `public/default.mp4`) предусмотрены заглушки. Если у объекта поле пустое или медиафайл не загрузился, автоматически отображается проектный дефолт.
- **Источник данных — mock-коллекция**: данные карточек получаются из типизированной коллекции `MOCK_ACTIVITIES` (`src/modules/mock.ts`) без необходимости запущенного бэкенда.
- **Подключение к веб-сервису**: в `src/modules/activitiesApi.ts` реализован модуль обращения к REST API бэкенда (`/api/network-activities`) с автоматическим fallback на mock-объекты. В `vite.config.ts` настроен reverse-proxy на `http://localhost:8000`.

## 2. Страницы приложения, элементы управления и поля

### 1. Страница «Лента» (`/` или `/feed`)
Полноэкранный вертикальный формат просмотра активностей (аналог ленты из ЛР-1 и TikTok-формата из методички).

* **Поля и отображаемая информация:**
  - Логотип сервиса в верхнем левом углу: `NETWORK ACTIVITIES`.
  - Полноэкранный медиаплеер: видеоролик сетевой активности в `<video autoplay loop muted playsinline>` (с автоподстановкой `/default.mp4` или `/default.png` при отсутствии URL).
  - **Название активности** (`activity_title`).
  - **Описание активности** (`activity_description`) со сворачиванием текста до 2 строк.
  - **Индикатор среднего трафика** (⚡ `average_traffic_mbps` Мбит/с).
  - **Индикатор максимальной задержки** (⏱ `max_latency_ms` мс).
  - **Счетчик отметок «Нравится»** (♡ `likes_count`).

* **Кнопки и действия:**
  - **Кнопка «Еще / Свернуть»**: раскрывает полное описание активности либо сворачивает его обратно.
  - **Кнопка «Лайк» (♡)**: интерактивная кнопка, позволяющая гостю поставить/снять отметку «нравится» с мгновенным пересчетом количества.
  - **Круглая кнопка «Далее»** (со стрелкой): циклический переход к следующей активности в списке карточек.

---

### 2. Страница «Плитка» / Каталог (`/catalog`)
Каталог опубликованных сетевых услуг в виде плиточной сетки в 2 колонки с расширенной фильтрацией и сортировкой.

* **Поля ввода и фильтрации (компоненты React-Bootstrap):**
  - **Поле поиска по названию** (`Form.Control`): строка поиска с иконкой лупы и плейсхолдером `Поиск по названию активности...`.
  - **Слайдер ограничения трафика** (`Form.Range`): ползунок от 0 до 150 Мбит/с с живым числовым бейджем текущего значения (`0 — 150 Мбит/с`).
  - **Выпадающий список сортировки** (`Form.Select`):
    - *По умолчанию (по ID)*;
    - *По возрастанию трафика (⚡)*;
    - *По убыванию трафика (⚡)*;
    - *По минимальной задержке (⏱)*;
    - *По популярности (♡ лайки)*.

* **Кнопки:**
  - **Кнопка «Применить»** (`Button` с cyan-акцентом): подтверждение формы фильтрации.
  - **Кнопка «Сброс»** (`Button outline`): возврат фильтров к начальным значениям (очистка поиска, сброс слайдера на 150 Мбит/с).
  - **Кнопка «Сбросить фильтры» в пустом состоянии**: появляется при отсутствии результатов поиска.

* **Карточки услуг (`ActivityCard`):**
  - Изображение обложки с обработчиком `onError` и fallback на `/default.png`.
  - Верхняя строка параметров: допустимый пинг ⏱ `max_latency_ms` мс и лайки ♡.
  - Название активности `activity_title`.
  - Требуемый трафик: ⚡ `average_traffic_mbps` Мбит/с.
  - **Клик по карточке**: переход на страницу подробного описания услуги (`/detail/:id`).

### 3. Страница «Подробнее» (`/detail/:id`)
Детальный просмотр выбранной сетевой услуги с полной технической сводкой и медиаплеером.

* **Поля и отображаемая информация:**
  - Бейдж идентификатора активности (`ID: #id`).
  - Статус-бейдж (`Опубликовано`).
  - Медиа-блок: воспроизведение видеоролика превью либо статичной картинки (с гарантированным fallback на проектные ассеты).
  - Название сетевой услуги.
  - Полное развернутое описание предназначения услуги в сети.
  - Блоки метрик:
    - ⚡ Требуемый средний трафик (Мбит/с);
    - ⏱ Максимально допустимая задержка сети (мс);
    - ♡ Количество отметок «Нравится».

* **Кнопки:**
  - **Кнопка «← Назад к плитке»**: возвращает пользователя на страницу каталога (`/catalog`).
  - **Кнопка «Следующая активность →»**: переходит к следующей услуге в порядке текущего списка, обеспечивая сквозную навигацию.

## 3. Нижняя навигационная панель (`BottomNavbar`)

Закреплена внизу мобильного контейнера (`position: fixed; bottom: 0`) и содержит **4 пункта** согласно заданию:

| № | Пункт | Иконка | Маршрут | Доступность для гостя | Поведение |
|---|---|---|---|---|---|
| 1 | **Лента** | Камера / Reels | `/feed` | **Доступен** | Переход на страницу полноэкранной ленты |
| 2 | **Добавление** | Плюс `+` | — | **Недоступен (`disabled`)** | Заблокирован, всплывает Tooltip: *«Доступно только авторизованным пользователям»* |
| 3 | **Плитка** | Сетка `▦` | `/catalog` | **Доступен** | Переход в каталог с фильтрацией и карточками |
| 4 | **Вход** | Профиль / Вход `→]` | — | **Недоступен (`disabled`)** | Заблокирован, всплывает Tooltip: *«Режим гостя: вход отключен»* |

## 4. Запуск проекта

### Вариант 1: Локальный запуск через Node.js
```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (порт 3000)
npm run dev

# Сборка продакшн-бандла
npm run build
```
Приложение откроется по адресу: [http://localhost:3000](http://localhost:3000)

### Вариант 2: Запуск в Docker через docker-compose
```bash
docker-compose up --build
```
Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)
