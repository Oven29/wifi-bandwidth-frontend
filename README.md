# Wi-Fi Bandwidth Router — Frontend (Лабораторная работа №5)

Базовое SPA-приложение на **React**, **TypeScript**, **Vite** и **React-Bootstrap** для просмотра профилей сетевой активности и распределения пропускной способности Wi-Fi роутера.

---

## Архитектура проекта

Проект построен по модульной архитектуре **FSD (Feature-Sliced Design)** с полным разделением логики, интерфейса и стилей:

```text
src/
├── app/                  # Конфигурация приложения и роутинга (React Router)
├── entities/             # Сущности предметной области (NetworkActivity)
│   └── activity/
│       ├── model/        # Типы данных (types.ts) и mock-коллекция (mock.ts)
│       └── ui/           # Компонент карточки активности (ActivityCard.tsx)
├── features/             # Сценарии пользователя
│   └── activity-filter/  # Фильтрация и поиск активностей по onSubmit (ActivityFilter.tsx)
├── widgets/              # Составные блоки интерфейса
│   ├── bottom-navbar/    # Нижняя панель навигации на 4 пункта (BottomNavbar.tsx)
│   └── media-viewer/     # Плеер с fallback на видео/фото по умолчанию (MediaViewer.tsx)
├── pages/                # Страницы SPA
│   ├── FeedPage.tsx      # Лента активностей (гостевой режим)
│   ├── CatalogPage.tsx   # Плитка карточек с формой фильтрации
│   └── DetailPage.tsx    # Детальная страница активности
└── styles/               # ВСЕ СТИЛИ ВЫНЕСЕНЫ В ОТДЕЛЬНУЮ ДИРЕКТОРИЮ
    ├── index.css         # Глобальные стили и CSS-переменные темной темы
    ├── pages/            # Стили страниц (FeedPage.css, CatalogPage.css, DetailPage.css)
    ├── widgets/          # Стили виджетов (BottomNavbar.css, MediaViewer.css)
    ├── features/         # Стили фич (ActivityFilter.css)
    └── entities/         # Стили карточек (ActivityCard.css)
```

## Описание страниц приложения

### 1. Страница «Лента» (`/feed` или `/`)
Полноэкранный вертикальный интерфейс просмотра активностей в стиле коротких медиа-карточек (TikTok/Reels).
* **Поля и данные:**
  * Заголовок и порядковый номер активности (`currentIndex + 1 / total`).
  * Название активности (`activity_title`).
  * Текстовое описание профиля нагрузки сети (`activity_description`).
  * Метрики нагрузки: средний трафик (`average_traffic_mbps`, Мбит/с) и максимальная задержка (`max_latency_ms`, мс).
* **Кнопки и элементы управления:**
  * **Медиа-контейнер (клик):** переход к следующей активности по клику в любую область экрана.
  * **Кнопка «Подробнее / Свернуть»:** раскрывает или скрывает полный текст описания.
  * **Кнопка «♡ Лайк»:** переключает отметку «Нравится» с анимацией и инкрементом локального счетчика.
  * **Кнопка «↑» (Вверх):** переход к предыдущей активности в списке.
  * **Кнопка «↓» (Вниз):** переход к следующей активности в списке.

---

### 2. Страница «Плитка» (`/catalog`)
Каталог всех сетевых профилей в виде адаптивной сетки карточек с формой фильтрации и поиска.
* **Поля формы фильтрации (`ActivityFilter`):**
  * Текстовое поле ввода: `Поиск по названию активности...` (поиск по названию и описанию).
  * Ползунок диапазона (`Form.Range`): `Максимальный объем трафика` (от 0 до 150 Мбит/с с шагом 5).
  * Информационный бейдж текущего значения фильтра (например, `75 Мбит/с`).
* **Кнопки управления:**
  * **Кнопка «Найти активности» (submit формы):** применяет критерии фильтрации к mock-коллекции по событию `onSubmit` (в соответствии с лекцией 9, слайд 6).
  * **Кнопка «Сбросить»:** очищает строку поиска, возвращает ползунок в максимальное значение и восстанавливает полный список карточек.
  * **Карточка активности (клик):** переход на страницу детального просмотра активности (`/detail/:id`).

---

### 3. Страница «Детальный просмотр» (`/detail/:id`)
Страница подробных характеристик выбранного профиля нагрузки роутера.
* **Поля и данные:**
  * Идентификатор активности (`Badge: ID: #...`).
  * Медиа-плеер активности с автоматическим fallback на заглушку проекта.
  * Полное название активности и статус публикации (`Опубликовано`).
  * Развернутое описание сетевого сценария.
  * Блок метрик: Средний трафик (Мбит/с), Максимальный пинг (мс), Количество лайков.
* **Кнопки:**
  * **Кнопка «← Назад в каталог»:** возвращает пользователя к списку карточек в плитке.
  * **Кнопка «Следующая активность →»:** циклический переход к следующей карточке без возврата в общий каталог.

---

### 4. Навигационная панель (`BottomNavbar`)
Фиксированное нижнее меню навигации из **4 пунктов** (в соответствии с заданием Лабораторной №5):
1. **Лента** — активна, переключает роут на `/feed`.
2. **Добавление** — **заблокирована** для гостя (`disabled`, иконка 🔒, всплывающая подсказка *«Доступно только авторизованным пользователям в ЛР6»*).
3. **Плитка** — активна, переключает роут на `/catalog`.
4. **Вход** — **заблокирована** для гостя (`disabled`, иконка 🔒, всплывающая подсказка *«Авторизация будет реализована в ЛР6»*).

---

## Реализация медиа по умолчанию (Fallback)

В компоненте `MediaViewer` и карточках `ActivityCard` предусмотрена двухуровневая защита от отсутствующих или поврежденных медиа-ресурсов:
1. Если ссылка на видео отсутствует или браузер возвращает ошибку загрузки видео (`onError`), происходит переключение на превью-изображение (`preview_image_url`).
2. Если изображение отсутствует или ссылка битая (`onError`), автоматически подставляется локальное векторное изображение проекта `/default.svg`.
